# 描边额外抖动修正 · 2026-10-16

本轮消除了固定会议室中可复现的额外描边闪动。未宣称全游戏视觉达标。

后续动态检查另发现多级目标跨帧延迟，已按实际原生绘制顺序调整目标注册，并在 2880×1676 下验证首帧与稳定帧完全一致；完整路线、缩放与切场结果见 [动态同步修正](outline-motion-fix.md)。下面的“未完成”保留本次固定机位测试结束时的状态。

## 定位与修改

- 冻结相机、人物、光照和剧情，原生直接渲染五张截图完全一致。
- 关闭景深、保留原先的屏幕深度描边，同笔触下镂空边缘仍变化；再关闭描边和扰动，变化归零。
- 仅拆分景深不能消除这部分变化。最终将主场景渲染到独立颜色目标并挂接可读深度 attachment；STYLIZE 与 DOF 在各自的全屏 pass 中读取明确绑定的主场景数据，不再在主相机的读屏材质中读取临时深度。
- 描边先按像素栅格化，再由原版 32 点景深核双线性采样。保留原幅度、4 Hz 定格笔触、第一章 paper=false。UI 仍为 NVG。
- 新增目标在释放前解绑 viewport、sampler 和 linked depth；先回收 surface wrapper，再销毁父纹理。
