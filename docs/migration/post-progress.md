## 独立数值对照及局限

tests/compare-frost-kernel.py 从冻结 post.js 读取滤波权重，以原生关闭后处理截图逆算线性颜色，独立计算模糊和合成。原生结果相对该数学参考的 MAE（0–255）：右墙无 UI 区域 0.277，柜台无 UI 区域 1.309；清晰左侧 1.181，角色 2.003。逐区域数值、坐标和 P99 保存在 frost-kernel-comparison.json。

这不是 H5 场景截图相似度。输入来自原生画面，存在 8 位量化、裁剪高亮无法恢复 HDR、不同渲染路径的边缘差异，以及 UI 污染限制。不能将这些数值换算成“95% 已通过”。
